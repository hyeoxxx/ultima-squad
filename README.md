# ⚔️ 울티마 스쿼드 (팬메이드)

메이플스토리 「[미니게임] 울티마 스쿼드」 이벤트를 브라우저에서 그대로 즐길 수 있게 재현한 방치형 게임입니다.

👉 **https://hyeoxxx.github.io/ultima-squad/**

## PIP 모드
전투 화면 아래 **📺 PIP** 버튼으로 전투 화면을 항상 위에 떠 있는 작은 창으로 띄워요 (PC 크롬/엣지). 설정 탭에서 방식을 고를 수 있어요.
- **영상 PIP (기본)**: 유튜브 PIP처럼 창 상단 바가 없어요. 인벤토리·골드·큐브·상자·용병 경험치·최근 획득·진행도가 HUD로 그려진 영상이라 보기만 돼요.
- **문서 PIP**: PIP 창 안에서 상자·반복 버튼을 누를 수 있어요. 크롬 정책상 창 위에 주소 바가 붙어요.

## 설정
전체 / 배경음악 / 스킬 효과음 / 몬스터 효과음 / 게임 효과음 볼륨을 따로 조절하고, PIP 방식을 고를 수 있어요.

## 자동 기능 (자동 탭)
원작에 없는 편의 기능이라 각각 켜고 끌 수 있어요. 다 켜두면 손대지 않아도 카오스 3-10까지 알아서 진행됩니다 (`tools/autotest.js`).
- 좋은 장비 자동 장착 (전투력 = 화력×생존력 기준), 인벤토리 자동 정리 (합성 → 낮은 단계 분해)
- 자동 큐브 (목표 옵션/줄 수, 남길 큐브 수), 스킬 자동 배치 (보스 기믹 스킬 포함)
- 자동 재도전 (실패 후 N분마다, 일반 클리어 후 카오스로), 에스페시아 상자 자동 소환
- 유틸리티 자동 구매 (우선순위 지정), 용병 자동 영입
- 알림 (인벤토리 가득 참 / 보스 도달 / 최초 클리어 / 큐브 목표), 이번 접속 리포트, 인벤토리 ▲ 업그레이드 표시

## 코인 강화
원작 코인샵 아이템 대신 코인으로 영구 강화를 사요.
- 스쿼드 코인: 경험치 +5%×10, 공격력/마력 +4%×10, HP +4%×10, 오프라인 효율 +5%p×4
- 카오스 스쿼드 코인: 경험치/공격력/HP +2%×50, 장비 드롭 +3%×20, 큐브 드롭 +10%×20, 골드 +3%×20

## 원작 그대로 재현한 것
- **용병 3종**: 전사(기본), 궁수(1-6 클리어 + 10만 골드), 마법사(2-6 클리어 + 궁수 보유 + 200만 골드). 최대 60레벨, 레벨에 따라 외형 변화
- **스킬 18종 + 기본 공격**: 퍼센트 데미지·대상 수·재사용 대기시간 그대로. 슬롯 1→3칸(1-10 / 2-10 클리어 후 25만 / 300만 골드). 앞 슬롯부터 사용, 해제 시 3초 재장착 대기, 전투 중 장착 시 쿨타임 대기
- **장비 96종**(3직업 × 4부위 × 8단계): 단계별 요구 레벨, 기본 옵션 5품질, 잠재능력 등급과 줄 수, 분해 골드, 9개 합성
- **잠재능력**: 등급별 옵션 가중치와 수치표, 부위 전용 옵션(분노/사랑/무적/데미지 무시), 훈련용 큐브(2만 골드), 전/후 선택
- **스테이지**: 일반/카오스 × 3지역 × 10스테이지, 지역별 맵 12종, 스테이지별 드롭 장비 단계, 몬스터 처치 골드(실측치), 보스 스테이지 1회 클리어, 실패 시 한 단계 아래 반복, 반복 플레이·포탈
- **지역 보스 기믹**: 핑크빈(체력 회복 → 폭풍의 시 필요), 악화된 조화의 정령(전원 중독 → 힐 + 헤븐즈 도어), 오디움의 수호병(15초 광역 즉사기 → 40레벨 극딜기)
- **오프라인 보상**: EXP·골드만, 마지막으로 클리어한 스테이지 기준, 기본 16시간(최대 24시간)
- **에스페시아 상자**: 하루 1회, 레어→레전드리 성장
- **유틸리티·훈장**: 가격 그대로

## 그래픽
`assets/` 의 그림은 [maplestory.io](https://maplestory.io) (KMS 389 클라이언트 데이터)에서 받았습니다 (`tools/fetch_assets.py`).
- 용병: 실제 메이플 캐릭터 렌더링. 레벨 1~19 / 20~39 / 40+ 외형 3단계, 장착한 무기 외형 반영 (8단계 × 3직업)
- 장비 아이콘 96종: 울티마 장비와 같은 외형의 원본 아이템 아이콘
- 몬스터 21종: 각 맵에 실제로 나오는 몬스터와 보스 (핑크빈, 악화된 조화의 정령, 오디움의 수호병 등) 애니메이션
- 맵 배경 12장: 원본 맵의 배경 레이어를 합성, 발판은 각 맵이 쓰는 타일셋 (`tools/fetch_tiles.py`)

- 스킬 아이콘·이펙트 21종: 같은 이름의 메이플 스킬(오라 블레이드, 디바이드, 폭풍의 시, 체인 라이트닝, 헤븐즈 도어, 조디악 레이 등)의 시전·투사체·피격 이펙트 (`tools/fetch_skills.py`)

- 사운드: 스킬 사용·타격음, 몬스터 피격·사망음, 레벨업·아이템 획득 등 효과음, 맵별 BGM 10곡 (`tools/fetch_sounds.py`)

울티마 스쿼드 전용 리소스(미니게임 UI, 상자)는 해당 클라이언트 버전에 없어서 직접 그렸습니다.

## 추정한 값
몬스터 능력치, 용병 레벨별 스탯, 경험치 표, 드롭 확률 같은 비공개 수치는 **인벤 정리글의 스테이지별 권장 레벨**에 맞춰 시뮬레이션으로 보정했습니다 (`tools/calibrate.js`, `tools/validate.js`, `tools/playtest.js`).
